# dominobeat-legal

도미노 비트(Domino Beat) 앱의 법적 고지 페이지입니다. GitHub Pages로 공개합니다.

| 문서 | 주소 |
|---|---|
| 개인정보 처리방침 (한국어 `#ko`, 영어 `#en`) | https://turning78.github.io/dominobeat-legal/privacy/ |

- 앱의 설정 화면 "개인정보 처리방침" 버튼이 이 주소에 언어 절(`#ko` 또는 `#en`)을 붙여 엽니다.
- Play Console의 개인정보처리방침 칸에는 언어 절이 없는 주소를 넣습니다.
- 앱이 다루는 정보가 바뀌면 이 페이지와 시행일을 함께 고칩니다.
